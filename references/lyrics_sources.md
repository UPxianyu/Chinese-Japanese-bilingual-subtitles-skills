# 歌词来源与提供方式

歌词来源应当由用户主动提供，不主动调用第三方歌词抓取接口。

## 优先级

1. 用户自行寻找字幕网站或官方歌词页，并粘贴/上传的原文歌词与译文。
2. 用户提供的 LRC、TXT、JSON 文件。
3. ASR 转写 + 校对 + 翻译兜底。

如果用户没有提供歌词来源，先询问；问不到时使用 ASR 转写后校对翻译，并把来源标注为 `ASR`。

## 用户提供文件

推荐用户提供以下任一形式：

- 每首歌的 LRC 文件；
- 一个 JSON 文件，字段包含 `name`、`artist`、`lyrics`、`tlyric`；
- 纯文本歌词和对应译文。

用户也可以直接把歌词和译文分段粘贴在对话里，agent 会整理成后续对轴所需的结构。
